# SIG

Página del curso **Fundamentos de SIG** · Especialización en SIG · Universidad de Manizales.

Sitio estático (HTML, CSS y JavaScript, sin compilación): presentaciones de las tres sesiones, ejercicios para practicar en QGIS y datos descargables.

- `index.html`: inicio
- `presentaciones/`: sesiones 1, 2 y 3
- `ejercicios.html`: ejercicios con respuestas
- `descargas/datos_curso.zip`: datos para QGIS

Despliegue en Vercel: importar el repositorio, Framework Preset **Other**, sin comando de build.
