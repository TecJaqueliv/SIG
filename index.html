Datos para QGIS

Descargue este archivo, descomprímalo en una carpeta fácil de encontrar (por ejemplo, Documentos) y no mueva las carpetas después de crear un proyecto.

Descargar datos del curso (.zip)
  • DATA MUNDO: países, ciudades, ríos, lagos y zonas UTM del mundo.
  • datos_reales: comunas, barrios, equipamientos, perímetro urbano y red vial de Manizales (Alcaldía de Manizales).
  • datos_practica: datos ficticios de práctica (zonas de amenaza, casos con fecha) y un plano sin coordenadas para georreferenciar. No representan la realidad.

¿No tiene QGIS? Descargue la versión LTR desde qgis.org.
